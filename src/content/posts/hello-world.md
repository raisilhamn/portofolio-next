## Why Another Blog?

The internet is saturated with blogs, tutorials, and hot takes. Yet here I am, adding another node to the graph. My reasoning is simple: **writing clarifies thought**.

> "If you can't explain it simply, you don't understand it well enough."
> &mdash; Albert Einstein

This site is my attempt to explain things simply.

## Design Philosophy

You might notice this site looks... plain. That is intentional. Inspired by the typography of Donald Knuth's TeX and the minimalism of academic writing, this site prioritizes:

1. **Readability** &mdash; serif type, generous line height, narrow columns
2. **Simplicity** &mdash; no JavaScript bloat, no popups, no tracking
3. **Speed** &mdash; static generation where possible, minimal dependencies

### What's Under the Hood

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS with custom LaTeX-inspired theme
- **Content**: Markdown with frontmatter, rendered server-side
- **Fonts**: Source Serif 4 for body, Source Code Pro for code
